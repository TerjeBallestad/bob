# Tokens

Bob's look lives in CSS custom properties on `:root`, in `src/tokens/*.css`. One dark theme.
The values come from the source dashboard, exact. Everything on this page is computed from those
files, so it cannot drift from them. TOKENS.md in the package says the same in text.

## Colour: scales, then roles

Colour has two layers.

- A **scale** holds the values. Each step is a token: `--gray-12`, `--indigo-9`. An alpha step is a
  solid step at an opacity: `--indigo-9-a10` is indigo 9 at 10%.
- A **role** says what a colour is for and points at a step: `--bg-card` is `--gray-8`. Each role
  is one token, named like its Tailwind class (`bg-card`), and is for one property: a background,
  a border or a text colour. Components use roles, never steps.

A colour literal appears only in a scale step. The token test fails on any other.

## Contrast

The ratios are WCAG 2.2, computed from the tokens. Tints are painted over the surface they sit on
before the ratio is taken.

<Story of={TokenStories.ContrastTextOnSurfaces} />

`--text-muted` (placeholders, section labels) and `--text-faint` (timestamps, ages) fail AA everywhere. They
are kept as they are until the design pass, which decides each use: lift the colour, or accept the
text as decorative.

<Story of={TokenStories.ContrastPairsInUse} />

White on `--bg-danger` (Button danger, 3.9:1) and `--text-danger` on `--bg-danger-tint` (Chip danger, 4.1:1)
fail AA.

## Type

<Story of={TokenStories.Type} />

In a Tailwind app Bob's type is a set of text styles (DD-038). One class sets the font size, the
line height, and where the style needs them the letter spacing and the weight: `text-label`, not
`text-tiny font-semibold tracking-label`. The ramp names (`text-micro` to `text-display`) are each
size's plain style; `text-id`, `text-label`, `text-note`, `text-subhead`, `text-item` and `text-heading` are
second styles at a size, named by role. An app adds no `leading-*`, `tracking-*` or font weight
next to a style. A style cannot set case or family, so a label adds `uppercase` and an id adds
`font-mono`. `text-base` is Bob's 13px, not Tailwind's 1rem.
