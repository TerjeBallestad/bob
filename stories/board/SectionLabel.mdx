## When to use

- To name a group of rows or cards, with a dot for its state and a count or action on the right.

## When not to use

- As a page or modal title. Those are headings in the type scale (`--fs-title`, `--fs-doc`).

<DoDont>
<Do>

- Write the name in sentence case. CSS sets the capitals and the letter spacing.
- Keep the action small: a `mono` Chip for a count, or a ghost `sm` Button.

</Do>
<Dont>

- Write the name in capitals. A screen reader may spell it letter by letter.

</Dont>
</DoDont>

## Accessibility

<Gap>The label is a `<div>`, not a heading, and it takes only `style`. A screen reader user cannot jump between sections. Wrap it in an `<h2>` or `<h3>` where it starts a section.</Gap>
