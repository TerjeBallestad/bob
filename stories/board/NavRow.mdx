## When to use

- For the views of an app in its sidebar: Inbox, Planned, Done.

## When not to use

- For a list of records. Use [ListRow](?path=/docs/board-listrow--docs).
- For an action. Use [Button](?path=/docs/core-button--docs) with `variant="ghost"`.

<DoDont>
<Do>

- Mark exactly one row `active`: the view on screen.
- Show a count when it helps the user decide where to go. `count={0}` shows 0; leave it out to show none.

</Do>
<Dont>

- Put a long label in it. It truncates at the sidebar's width.

</Dont>
</DoDont>
