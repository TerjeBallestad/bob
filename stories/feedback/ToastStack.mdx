## When to use

- Once, at the root of the app, holding every [Toast](?path=/docs/feedback-toast--docs).

## When not to use

- Inside a scrolling panel or a modal. It is fixed to the window.

## Accessibility

ToastStack is built on Base UI's toast viewport. It is a live region: `role="region"`,
`aria-live="polite"`, named "Notifications".

- A screen reader reads only the changes to a live region that was already on the page. Keep the
  stack mounted, also when it is empty, and each toast the app adds is read.
- The toasts keep their own roles: `status`, or `alert` for an error.
