## When to use

- Once, at the root of the app. Every [Toast](?path=/docs/feedback-toast--docs) shows in it.

## When not to use

- Inside a scrolling panel or a modal. It is fixed to the window.

## Usage

```tsx
export const toast = createToastManager();

<ToastStack toastManager={toast} timeout={4000} limit={3}>
  <App />
</ToastStack>
```

- `children` is the app. A component inside it can call `useToastManager()`.
- `timeout` (4000 ms) is how long a toast stays. 0 keeps it until the user closes it.
- `limit` (3) is the most toasts on screen. An older one waits, hidden, until a newer one closes.

## Accessibility

- The stack is a region named "Notifications". F6 moves focus to it from anywhere on the page.
- The stack is not a live region. Two hidden live regions beside it read each toast once: polite for a success, assertive for an error. They are in the page before the first toast, so keep the stack mounted.
