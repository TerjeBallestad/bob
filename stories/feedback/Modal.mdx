## When to use

- To confirm an action that is hard to undo: archive, delete, leave with unsaved changes.
- For a short form that belongs to one action: rename, new ticket.

## When not to use

- To tell the user something went well. Use a [Toast](?path=/docs/feedback-toast--docs).
- For a long document or a record to read beside the board. Use a side panel.
- For an error the user can do nothing about in this step. Show it where it happened.

## Usage

Modal keeps no state. The parent opens it and closes it in `onClose`. The × button, Escape and a
click on the backdrop call it:

```tsx
const [open, setOpen] = useState(false);
<Button variant="danger-ghost" onClick={() => setOpen(true)}>Archive</Button>
<Modal
  open={open}
  title="Archive SB-042?"
  onClose={() => setOpen(false)}
  footer={<>
    <Button variant="ghost" onClick={() => setOpen(false)}>Cancel</Button>
    <Button variant="danger" onClick={archive}>Archive</Button>
  </>}
>
  The ticket leaves the board. You can find it again under Archive.
</Modal>
```

The box is 560px wide (92% of a narrow screen) and scrolls past 80% of the screen height.

Modal is built on Base UI's Dialog. It renders in a portal at the end of `<body>`, so a parent's
`overflow` or `transform` does not clip it. A test that looks for the dialog must search the whole
page, not only the parent's element.

## Interaction test

**Open and close (test)** runs the wiring above in a play function. Enter on the opener opens the
dialog, and focus moves to it. Tab reaches the close button, and Enter closes it. Escape closes it.
Each time, focus goes back to the opener. A click inside the box keeps it open, and a click on the
backdrop closes it. CI runs it in the built Storybook.

## Accessibility

Base UI's Dialog does the keyboard and focus work.

<Keys rows={[
  ['Tab', 'Moves through the × button, the body and the footer buttons. After the last one it goes back to the first: focus stays in the dialog.'],
  ['Shift Tab', 'Moves back, and wraps from the first to the last.'],
  ['Enter Space', 'On × or a footer button: runs it.'],
  ['Escape', 'Closes the dialog: calls onClose.'],
]} />

- When it opens, focus moves to the box, and a screen reader reads its title. The first Tab
  reaches the × button.
- When it closes, focus goes back to the element that had it, usually the opener.
- While it is open, the page behind it is hidden from screen readers.
- The box is a `dialog` with `aria-modal="true"`, named by its title (`aria-labelledby`). The
  title is an `<h2>`. The × button's name is "Close".
