## Install

```sh
npm i @terjeballestad/bob
```

Bob needs React 18.3 or later: `react`, `react-dom` and `@types/react` are peer dependencies.

## Add Bob to your CSS

Bob works with Tailwind v4. Add one line after your Tailwind import: ```css
@import "tailwindcss";
@import "@terjeballestad/bob/tailwind.css";
```

Your Tailwind build now writes Bob's classes (`btn`, `chip`, `ticket-card`), and only the ones in use.

## Use a component

```tsx
import { Button } from '@terjeballestad/bob';

<Button variant="primary" onClick={save}>Save</Button>
```

The import also loads Bob's webfonts. Your utilities win over Bob's classes: `<Button className="px-8">` gets 32px of side padding.

## Two rules for your CSS

- **Put element rules in `@layer base`.** An unlayered rule such as `button { color: inherit }`
  beats every layered class, Bob's too.
- **Preflight changes the look.** Bob brings its own reset. With Tailwind's preflight, text sits
  at line-height 1.5 and Bob's rows grow. To keep Bob's look, import Tailwind's theme and
  utilities only: ```css
  @layer theme, base, components, utilities;
  @import "tailwindcss/theme.css" layer(theme);
  @import "tailwindcss/utilities.css" layer(utilities);
  @import "@terjeballestad/bob/tailwind.css";
  ```

## Tokens

Every value is a CSS custom property on `:root`.

- A **scale** holds the colours: `--gray-1` to `--gray-26`, and eight hues on the 12 steps of
  Radix Colors.
- A **role** says what a colour is for and points at a step: `--bg-card` is `--gray-8`. Each role is one token, named like its class.
  Components use roles, never steps.

In Tailwind, the tokens are classes: `bg-card`, `text-secondary`, `border-subtle`, `rounded-btn`,
`font-mono` (DD-033). A role makes a class only for its property: there is no `text-card`. A scale
step works with every utility: `bg-gray-3`, `text-indigo-9`.

[Tokens](?path=/docs/tokens--tokens) shows every scale and role, and the contrast of each text
role on each surface.

## Conventions

- **Overrides.** Components that wrap a native element (Button, Chip, Input, Textarea,
  SearchInput) take `className` and every attribute of that element. Select's parts take
  `className` and Base UI's props. The others take `style`.
- **Little state.** Bob's components keep no state, with two exceptions from Base UI: Select
  keeps its value when the app passes `defaultValue`, and ToastStack keeps the list of toasts that
  `toast.add` fills.
- **No icons.** Bob shows state with dots, mono chips and a few unicode characters.
- **Tests.** Every story has a screenshot test with no pixel tolerance. The stories marked
  *(test)* are interaction tests, which CI plays in the built Storybook.
