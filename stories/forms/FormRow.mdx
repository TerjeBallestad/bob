## When to use

- For every field in a form: in a modal, a settings page, a new-record panel.

## When not to use

- For a search field in a toolbar. It has no visible label; give it an `aria-label`.

<DoDont>
<Do>

- Write the label as a noun in sentence case: **Name**, **Stage**. CSS sets it in capitals.
- Put one field in each row.

</Do>
<Dont>

- Put a sentence of help in the label. Write it below the field.

</Dont>
</DoDont>

## Accessibility

- With one element child, the label is linked to it: FormRow sets `htmlFor`, and gives the child
  an id if it has none. A click on the label focuses the field, and a screen reader reads it as
  the field's name.

<Gap>With several children the label is linked to none. Give the field an `aria-label`.</Gap>
