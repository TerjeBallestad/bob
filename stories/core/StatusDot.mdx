## When to use

- Before a name in a list, a sidebar row or a section label, to show its state.

| State | Means |
| --- | --- |
| `dashed` | Inbox or unset. The colour is always `--gray-23`. |
| `outline` | In progress. |
| `staged` | Staged: outline with a 25% fill. |
| `solid` | Done. |
| `live` | An agent works on it now. It pulses. |

<Canvas of={Stories.States} />

`square` makes a rounded square: use it for a different kind of thing in the same list, such as a
project beside its tickets.

## When not to use

- As the only sign of a state. Say it in text too, or in the row's label.
- For a count or a word. Use [Chip](?path=/docs/core-chip--docs).

<DoDont>
<Do>

- Keep one meaning per state across the app.
- Pass a colour role: `var(--bg-green)`, `var(--bg-accent)`.

</Do>
<Dont>

- Put more than one `live` dot in view without a reason. Motion pulls the eye.

</Dont>
</DoDont>

## Accessibility

- The dot is a `<span>` with no role and no name: a screen reader skips it. The state must be in
  text as well.

- The `live` pulse runs only when the system allows motion (`motion-safe`).
